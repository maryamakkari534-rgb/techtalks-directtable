# DirectTable

DirectTable is a direct ordering platform for independent restaurants, cafés, bakeries, meal-prep businesses, and licensed home kitchens.

The platform helps food businesses manage direct customer orders and make repeat ordering easier.

The first pilot will be with **La Rose Sucre**.

---

## Project Overview

### Problem

Local food businesses often receive orders through different channels such as WhatsApp, Instagram, and phone calls. During busy periods, this can cause order confusion and make it difficult to manage customer requests and previous orders.

### Target Users

- Independent restaurants
- Cafés
- Bakeries
- Meal-prep businesses
- Licensed home kitchens

### Proposed Solution

DirectTable provides businesses with a simple branded ordering platform where customers can browse the menu, place orders, choose pickup or delivery, and easily order again.

Restaurants will also have a simple dashboard to manage their incoming orders.

---

## Approved MVP

### Core Features

V1 will focus on:

- Mobile-friendly branded menu and direct ordering
- Simple order-management dashboard
- Pickup and defined delivery zones
- Basic customer and order history
- One simple reorder or loyalty feature
- Simple ordering without requiring a complicated registration process

The first pilot will be conducted with **La Rose Sucre**.

### Out of Scope

The following features are not part of V1:

- Built-in payment processing
- Live delivery tracking
- Advanced analytics
- Personalized recommendations
- Complex integrations

Payments will remain outside the platform.

## Contribution Workflow

The team will use a branch-based GitHub workflow.

Each task or feature will be developed on a separate branch.

Examples:

```text
feature/restaurant-menu
feature/orders
feature/customer-history
feature/delivery-dashboard
```

Team members should:

1. Create a branch for their task.
2. Make clear and meaningful commits.
3. Push the branch to GitHub.
4. Open a Pull Request.
5. Have the work reviewed by another team member before merging.

Example commit:

```bash
git commit -m "Add order creation feature"
```

## Security

Passwords, API keys, database credentials, and real customer data must never be committed to the repository.

Sensitive information will be stored in environment variables.
